# Space Tourism Website

A responsive and interactive **Space Tourism Website** built with Next.js, TypeScript, and Tailwind CSS.  
The project is inspired by modern UI challenges, showcasing clean layouts, smooth animations, and accessibility-first design.  

🌐 **Live Demo:** []  

---

## 🧰 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS  
- **Animations:** Framer Motion  
- **Tooling:** ESLint, PostCSS  

---

## ✨ Features (current & planned)

- **Multi-page layout** — Explore different sections like Home, Destination, Crew, and Technology.  
- **Responsive design** — Fully optimized for mobile, tablet, and desktop.  
- **Dark/Light mode support** (planned).  
- **Smooth animations & transitions** — Framer Motion for page transitions and UI interactions.  
- **Reusable components** — Modular and clean structure for scalability.  
- **Accessibility-first design** — Semantic HTML, ARIA roles, keyboard navigation.

## 🚀 Getting Started

1. Clone the repo:
    ```bash
    git clone https://github.com/kiitycode/space-tourism.git
    cd space-tourism
    ```

2. Install dependencies:
    ``` bash
    - npm install
    ```

3. Run the development server:
    ``` bash
    - npm run dev
    ```
    Opens http://localhost:3000 in your browser.
