# Circle-17 JavaScript Presentation (Slidev)

A Slidev presentation created by **Team Circle-17** for the JavaScript Fundamentals class (Second semester, 2025).  
This deck covers core JavaScript topics (functions, arrays, async patterns, DOM/BOM, events, API requests) and is styled with a custom theme, assets and interactive controls.

## 🔎 What this project contains
The Slidev deck is an interactive, markdown-driven slide presentation built with Slidev. It includes:
- Intro / cover slide with class and presenter info
- Member listing slide (Circle-17)
- Sections on Functions, Arrays, Rest/Spread, Callbacks, Promises & Async/Await
- Practical code examples and short exercises
- Key takeaways and next steps

Theme: `seriph` (custom) — uses `projectimg.jpg` as background and `slides.css` for extra styling.

---

## 🧰 Tech & tools

- **Slidev** — slide framework (Markdown + Vue)
- **Tailwind CSS** — utility styles used in slides

## 🚀 Getting started (run locally)

Make sure you have Node.js (v16+) and npm installed.

1. Clone (if not already local)
```bash
git clone https://github.com/kiitycode/my_alts.git
cd my_alts/Slidev/slidev-presentation
```

2. Install dependencies
```bash
npm install
```

3. Start dev server (open http://localhost:3030)
```bash
npm run dev
```
