# AYSRAEL Studios

**Premium Abuja-based music production studio website**
featuring a multi-section layout, audio samples, services overview, testimonials, and contact info.

## Demo
Live demo: [AYSRAEL Studios](https://my-alts-azure.vercel.app/)

## Features
- **Hero & Tagline** — "Create Your Legacy"
- **Studio Story** — Mission-driven text with brand voice
- **Services Offered** — Recording, live coverage, mixing/mastering, jingles, and promo assets
- **Audio Samples** — Embedded music segments available for playback and download
- **Testimonials** — Artist quotes to build trust
- **Contact & Booking** — Visible CTA, studio address, phone, and email

## Tech Stack & Setup
- Static site built with HTML, CSS, and vanilla JavaScript  
- Structured in folders:
/aysrael
├── index.html
├── contact.html
├── services.html
├── css/
├── js/
├── imgs/
├── audios/
└── README.md

## Deployment
Automated deployment via **Vercel**. Push to `main` → instant live update.

## How to Use Locally
1. Clone this repo  
2. Open `index.html` in your browser  
3. Edit files and **push to `main`** to trigger Vercel deployment
